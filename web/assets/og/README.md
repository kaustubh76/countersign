# Fonts for the share cards

The link-preview images (`opengraph-image.tsx` routes) are drawn with these fonts. All three are licensed under the
SIL Open Font License 1.1; each license is next to its font.

| File | Font | Source |
|---|---|---|
| `archivo-extracondensed-black.ttf` | Archivo, width 62.5, weight 900 | Google Fonts, subset to printable ASCII plus `·×…–—’` |
| `caveat-semibold.ttf` | Caveat, weight 600 | Google Fonts, subset to the same characters |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono, weight 500 | Google Fonts, unmodified (its license reserves the name "Plex") |
